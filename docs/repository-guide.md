## 1. Big Picture

VietASR implements a **4-stage self-improving training loop** for low-resource Vietnamese ASR:

```
Stage 1 ──► Stage 2 ──────────► Stage 3 ──────────────► Stage 4
  Initial      Extract k-means     SSL Pretraining         Fine-tune
  ASR Model    labels from         (HuBERT-style on        pretrained
  (50h data)   unlabeled audio     large unlabeled data)   model → ASR
               using Stage-1 model
```

Each iteration can repeat Stages 2–4, with each cycle generating better pseudo-labels and a stronger model. The repository also includes a standalone **POC web app** (`POC/`) that wraps inference via a REST/WebSocket API with a React frontend.

**Core frameworks used:**

| Framework | Role |
|-----------|------|
| [icefall](https://github.com/k2-fsa/icefall) | Training recipes, loss functions, utilities |
| [k2](https://github.com/k2-fsa/k2) | WFST-based decoding (CTC lattice, fast beam search) |
| [lhotse](https://github.com/lhotse-speech/lhotse) | Data manifests, fbank extraction, cut sets |
| PyTorch | Model definition and training loop |
| sentencepiece | Byte-pair encoding (BPE) tokenizer |

## 2. Root-Level Files

### `README.md`
The official entry-point document. Contains a high-level pipeline diagram, step-by-step commands to reproduce the full training cycle, checkpoint download instructions, and citation information. **Always read this first.**

### `pyproject.toml`
Root Python package definition (managed by `uv`). Declares:
- **Package name:** `vietasr`, **Python:** ≥ 3.11.9
- **Core runtime dependencies:** `torch`, `torchaudio`, `lhotse`, `sentencepiece`, `tensorboard`, `soundfile`, `huggingface-hub`, `kaldialign`, `matplotlib`, `pyyaml`, `rich`, `tqdm`
- **Pyright extra paths:** includes `POC/apps/web-backend` and `POC/apps/asr-server` so the IDE finds their sources.

> To install all dependencies: `uv sync` from the root.

### `uv.lock`
Auto-generated deterministic dependency lockfile by `uv`. **Do not edit manually.** Regenerated by `uv lock` or `uv sync`.

### `.python-version`
Pins the Python version for `pyenv` / `uv`. Contains a single version string (e.g., `3.11.9`).

### `setup.sh`
**Must be `source`d (not executed)** before running any script. Does three things:
1. Activates the `.venv` virtual environment.
2. Appends `external/icefall` and `ASR/zipformer` to `PYTHONPATH` so Python can import `icefall.*` and zipformer modules without installation.
3. Sets `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python` to prevent protobuf segfaults.

```bash
source setup.sh   # run this first in every new shell session
```

### `.gitignore`
Standard exclusions: `__pycache__`, `.venv`, `*.pt`, `data/`, `download/`, `exp/`, `.env`, node_modules, etc.

## 3. `ASR/` — Supervised ASR Training Pipeline

This directory contains everything needed to train the **initial supervised ASR model** and run inference/decoding. The model architecture is **Zipformer2** with an RNN-T (transducer) head.

```
ASR/
├── prepare.sh          # Data pipeline: manifest → fbank → BPE vocab
├── shared              # Symlink → SSL/shared (shared bash utilities)
├── local/              # Python data-prep scripts
│   ├── compute_fbank.py
│   ├── filter_cuts.py
│   ├── prepare_manifest.py
│   └── train_bpe_model.py
├── scripts/            # Launch scripts for training and decoding
│   ├── train.sh
│   └── decode.sh
└── zipformer/          # All model Python source code
    ├── train.py        # ★ Main training entry point
    ├── decode.py       # ★ Main decoding entry point
    ├── zipformer.py    # ★ Core Zipformer2 model definition
    └── ...             # (30+ supporting files)
```

---

### 3.1 `ASR/prepare.sh`
**Orchestrates supervised data preparation** in 3 stages (controlled by `--stage` and `--stop-stage`):

| Stage | What it does |
|-------|-------------|
| 1 | Reads `download/supervised/{train,dev,test}/` WAV+transcript files → creates lhotse manifests in `data/manifests/` |
| 2 | Computes 80-dim Mel filterbank features → stores compressed cuts in `data/fbank/` |
| 3 | Trains a SentencePiece BPE model with vocab size 2000 → saves to `data/lang_bpe_2000/bpe.model` |

**Input structure expected:**
```
download/
└── supervised/
    ├── train/data1/*.wav + filename.trans.txt
    ├── dev/...
    └── test/...
```

---

### 3.2 `ASR/local/` — Data Preparation Scripts

#### `prepare_manifest.py`
Scans `download/supervised/` directory tree. Reads `*.trans.txt` transcript files (format: `audio_id text`) and creates lhotse `RecordingSet` and `SupervisionSet` manifests (`.jsonl.gz`). Supports optional lowercasing via `--language` flag.

#### `compute_fbank.py`
Loads the manifests from `data/manifests/`, extracts 80-dim log Mel filterbank features using lhotse's `Fbank` extractor (25ms window, 10ms shift), and writes compressed `CutSet` objects to `data/fbank/`.

#### `filter_cuts.py`
Post-processing utility. Filters out cuts that are too short, too long, or have unusually high/low token-per-second rates. Useful for cleaning noisy labeled datasets.

#### `train_bpe_model.py`
Trains a SentencePiece BPE model on the transcript text file. Key arguments: `--lang-dir`, `--vocab-size` (default 2000), `--transcript`. Outputs `bpe.model` and `tokens.txt`.

---

### 3.3 `ASR/scripts/` — Launch Scripts

#### `train.sh`
Launches `zipformer/train.py` across 4 GPUs. Key arguments passed:
- `--world-size 4` (DDP)
- `--num-epochs 300`
- `--max-duration 1000` (max batch audio seconds)
- `--manifest-dir data/fbank`
- `--bpe-model data/lang_bpe_2000/bpe.model`
- `--enable-spec-aug 1` (SpecAugment data augmentation)

> **Architecture parameters are NOT passed here** — the script relies on defaults in `train.py`. To change the model size, modify defaults in `add_model_arguments()` inside `train.py`.

#### `decode.sh`
Runs decoding with `zipformer/decode.py`. Usage: `./scripts/decode.sh <epoch> <avg> <gpu_id>`. Uses greedy search by default.

---

### 3.4 `ASR/zipformer/` — Model Source Code

All Python files here are importable because `setup.sh` adds this directory to `PYTHONPATH`.

---

#### ★ `train.py`
**The primary training script.** 1,539 lines. Key responsibilities:

- **`add_model_arguments(parser)`** — Defines all architecture hyperparameters as CLI arguments with defaults. **This is the ONLY place to change model size.** Current defaults (Zipformer-Small, ~30M params):

  | Argument | Default | Description |
  |----------|---------|-------------|
  | `--num-encoder-layers` | `"2,2,2,2,2,2"` | Blocks per stack |
  | `--encoder-dim` | `"192,256,256,256,256,256"` | Hidden dim per stack |
  | `--feedforward-dim` | `"512,768,768,768,768,768"` | FF hidden dim per stack |
  | `--num-heads` | `"4,4,4,8,4,4"` | Attention heads per stack |
  | `--cnn-module-kernel` | `"31,31,15,15,15,31"` | Conv kernel per stack |
  | `--query-head-dim` | `"32"` | Q/K dim per head (constant) |
  | `--value-head-dim` | `"12"` | V dim per head (constant) |
  | `--downsampling-factor` | `"1,2,4,8,4,2"` | U-Net frame rates |
  | `--encoder-unmasked-dim` | `"192,192,256,256,256,256"` | Feature mask dim |
  | `--decoder-dim` | `512` | RNN-T decoder embedding |
  | `--joiner-dim` | `512` | Joiner hidden dim |

- **`get_encoder_embed(params)`** — Instantiates `Conv2dSubsampling` using `encoder_dim[0]` as output channels.
- **`get_encoder_model(params)`** — Instantiates `Zipformer2` by unpacking all comma-separated CLI args as tuples.
- **`get_decoder_model(params)`** — Instantiates the stateless RNN-T `Decoder`.
- **`get_joiner_model(params)`** — Instantiates the `Joiner`; uses `max(encoder_dim)` as input projection.
- **`get_model(params)`** — Assembles all components into `AsrModel`.
- **`train_one_epoch()`** / **`run()`** — DDP training loop with gradient scaling, model averaging, checkpoint saving, and TensorBoard logging.

---

#### ★ `zipformer.py`
**Core model definition.** 2,446 lines. Contains all model classes:

| Class | Description |
|-------|-------------|
| `Zipformer2` | Top-level encoder. Manages 6 stacks and the U-Net structure. |
| `Zipformer2Encoder` | A stack of `Zipformer2EncoderLayer` blocks with warmup-based layer drop. |
| `Zipformer2EncoderLayer` | **One Zipformer block.** Contains: MHAW + 2×SA + NLA + 3×FF + 2×Conv + 2×Bypass + BiasNorm. |
| `DownsampledZipformer2Encoder` | Wraps a stack with `SimpleDownsample` + `SimpleUpsample` for U-Net behavior. |
| `RelPositionMultiheadAttentionWeights` | Computes attention weight matrices using relative positional encoding. |
| `SelfAttention` | Lightweight SA that consumes pre-computed attention weights. |
| `NonlinAttention` | Attention variant with tanh gating; uses shared attention weights. |
| `FeedforwardModule` | Two-layer MLP: `Linear → SwooshL → Dropout → Linear`. |
| `ConvolutionModule` | Gated 1D depthwise convolution with GLU input projection. |
| `BypassModule` | Learnable channel-wise bypass scale (residual interpolation). |
| `SimpleDownsample` | Weighted-sum temporal pooling. |
| `SimpleUpsample` | Nearest-neighbor temporal repeat (no learnable params). |
| `CompactRelPositionalEncoding` | Compact log-atan relative positional encoding. |

> **Key design principle:** `Zipformer2` is fully generic. Every dimension is a constructor argument. The model size is entirely determined by the tuples passed in from `train.py`. **No hardcoded sizes inside this file.**

**Block internal architecture (per `Zipformer2EncoderLayer`):**
```
input
  ├── MHAW (computes attention weights once, shared by SA1, SA2, NLA)
  ├── FF1  (hidden = 3/4 × feedforward_dim)
  ├── NLA  (NonlinAttention, uses shared weights)
  ├── [Bypass mid]
  ├── SA1 + Conv1
  ├── FF2  (hidden = feedforward_dim)
  ├── SA2 + Conv2
  └── FF3  (hidden = 5/4 × feedforward_dim)
  → [Bypass end] → BiasNorm → output
```

---

#### ★ `decode.py`
Main decoding script (1,156 lines). Imports `add_model_arguments`, `get_model`, `get_params` from `train.py` — automatically uses the same architecture defaults. Supports: `greedy_search`, `modified_beam_search`, `fast_beam_search`, `fast_beam_search_nbest`, `fast_beam_search_nbest_LG`.

---

#### `model.py`
`AsrModel` — the top-level nn.Module that glues together `encoder_embed`, `encoder`, `decoder`, `joiner`, and optionally `attention_decoder`. Handles the RNN-T loss (`simple_loss` + `pruned_loss`) and optional CTC loss.

---

#### `subsampling.py`
`Conv2dSubsampling` — the frontend feature extractor. Architecture:
1. 3-layer Conv2d stack (1→8→32→128) reducing time by 2× and frequency by 4×
2. One `ConvNeXt` block for local 2D feature mixing
3. `Linear(128 × freq_bins, encoder_dim[0])` projection + `BiasNorm` + dropout

Output: `(N, (T-7)//2, encoder_dim[0])` — this is the 50Hz sequence fed to Stack 1.

---

#### `scaling.py`
**The largest file (~71K).** Contains all custom numerical stability modules:

| Module | Description |
|--------|-------------|
| `ScaledLinear` | `nn.Linear` with a learnable output scale; used with `ScaledAdam` |
| `BiasNorm` | Alternative to LayerNorm that preserves absolute magnitude info |
| `Balancer` | Per-channel activation constraints during backprop |
| `Whiten` | Penalizes correlated channels; improves gradient flow |
| `ScheduledFloat` | Float value interpolated between training steps |
| `SwooshR` / `SwooshL` | Custom activations replacing Swish |
| `ActivationDropoutAndLinear` | Fused activation+dropout+linear |
| `ChunkCausalDepthwiseConv1d` | Causal depthwise conv for streaming inference |

---

#### `optim.py`
`ScaledAdam` — the custom optimizer for Zipformer. Tracks per-parameter scale factors and applies updates relative to those scales. Also contains `Eden` — the custom LR scheduler (warmup + exponential decay tied to validation loss).

---

#### `decoder.py`
`Decoder` — Stateless RNN-T prediction network:
- `Embedding(vocab_size, decoder_dim)`
- `Conv1d(decoder_dim, decoder_dim, kernel_size=context_size, groups=decoder_dim//4)` — grouped convolution
- No recurrent layers (stateless by design for fast beam search)

---

#### `joiner.py`
`Joiner` — Combines encoder and decoder for RNN-T:
```python
encoder_proj:  Linear(max_encoder_dim, joiner_dim)
decoder_proj:  Linear(decoder_dim, joiner_dim)
output_linear: Linear(joiner_dim, vocab_size)
forward: output_linear(tanh(encoder_proj(enc) + decoder_proj(dec)))
```

---

#### `attention_decoder.py`
Optional cross-attention Transformer decoder that attends to encoder outputs. Used when `--use-attention-decoder True`. Not used by default.

---

#### `beam_search.py`
**Largest file in ASR (~122K).** Implements all decoding algorithms:
- `greedy_search` / `greedy_search_batch`
- `beam_search`
- `modified_beam_search` (with optional LM shallow fusion, LODR, n-gram rescoring)
- `fast_beam_search_one_best` / `fast_beam_search_nbest` / `fast_beam_search_nbest_LG` / `fast_beam_search_nbest_oracle`

---

#### `asr_datamodule.py`
`AsrDataModule` — Wraps lhotse `CutSet` objects into PyTorch `DataLoader`s. Handles dynamic batching by total audio duration, SpecAugment, MUSAN noise augmentation, and distributed sampling.

---

#### `encoder_interface.py`
Abstract base class `EncoderInterface` that `Zipformer2` inherits. Defines `forward(x, x_lens)` and `streaming_forward(x, states, ...)` signatures.

---

#### `export.py`
Exports a trained checkpoint to TorchScript (`.pt` JIT) or ONNX format. Imports `add_model_arguments` from `train.py` → uses the same architecture defaults automatically.

---

#### `pretrained.py`
Quick inference script for a single audio file. Given `--checkpoint` and `--tokens`, loads the model and runs `modified_beam_search`.

---

#### `pretrained_ctc.py`
Like `pretrained.py` but uses CTC decoding instead of RNN-T.

---

#### `ctc_decode.py`
Batch CTC decoding script. Supports CTC greedy and CTC prefix beam search.

---

#### `streaming_decode.py`
Simulated streaming decoding using chunk-wise causal attention (requires `--causal True` during training).

---

#### `merge_decode.py`
Merges transcription outputs from multiple decoding runs using ROVER or best-system selection.

---

#### `generate_averaged_model.py`
Averages `N` consecutive training checkpoints by weight averaging to produce a more stable final model. Example: `--epoch 30 --avg 10` averages epochs 21–30.

---

#### `label_smoothing.py`
Label smoothing cross-entropy loss for the optional attention decoder head.

---

#### `dataset.py`
Custom lhotse `Dataset` class that extracts feature tensors and supervision targets from `CutSet`. Handles padding and collation.

---

#### `my_profile.py`
FLOPs counter and latency profiler. Run to measure model compute cost on a given input length without training.

---

#### `jit_pretrained.py` / `jit_pretrained_ctc.py` / `jit_pretrained_streaming.py`
Inference scripts that load a **TorchScript-exported** model (from `export.py`). Useful for CPU-only deployment without the full Python training stack.

---

#### `onnx_check.py`
Validates an ONNX-exported model by running a test forward pass and comparing outputs to the PyTorch model.

---

#### `decode_stream.py`
`DecodeStream` class — maintains per-utterance streaming decoder state (cached encoder hidden states, partial hypothesis, left-context buffer).

---

#### `scaling_converter.py`
Converts a model trained with `ScaledLinear` and custom scaling modules into a standard PyTorch model (with regular `nn.Linear`) for ONNX export compatibility.

---

#### `test_scaling.py` / `test_subsampling.py`
Unit tests for the custom scaling modules and the Conv2dSubsampling forward pass. Run with `pytest`.

---

#### `utils.py`
Small utility functions: WER computation, text normalization for Vietnamese, result formatting helpers.

## 4. `SSL/` — Self-Supervised Pretraining Pipeline

This directory implements **HuBERT-style pretraining** adapted to use a Zipformer encoder. The SSL pipeline allows the model to leverage large amounts of unlabeled audio.

```
SSL/
├── prepare_ssl.sh         # Unlabeled data pipeline: VAD → manifest → fbank → split
├── shared/                # Shared bash utilities (n-gram LM tools, option parser)
├── local/                 # Data preparation Python scripts
├── scripts/               # Launch scripts for each SSL stage
└── zipformer_fbank/       # SSL model Python source code
    ├── pretrain.py        # ★ HuBERT-style pretraining script
    ├── finetune.py        # ★ ASR fine-tuning of pretrained model
    ├── hubert_ce.py       # ★ HuBERT cross-entropy loss model wrapper
    └── extract_kmeans_scripts/  # K-means label extraction tools
```

---

### 4.1 `SSL/prepare_ssl.sh`
5-stage pipeline for unlabeled data:
1. Build lhotse manifest from raw WAVs (`vietASR_ssl.py`)
2. Preprocess manifest (normalize, filter) (`preprocess_vietASR_ssl.py`)
3. *(Optional)* Compute fbank for test set
4. Split large manifest into shards of 200K cuts each (`lhotse split-lazy`)
5. Extract fbank features for all train shards in parallel

---

### 4.2 `SSL/local/` — SSL Data Preparation

#### `vad.py`
Voice Activity Detection using [FunASR's FSMN-VAD model](https://huggingface.co/funasr/fsmn-vad). Segments long audio files into shorter utterances (~3–30s). **First step before any feature extraction on unlabeled data.**

#### `vietASR_ssl.py`
Scans the unlabeled audio directory and creates a lhotse manifest (without transcripts). Outputs `*.jsonl.gz` files describing each audio segment.

#### `preprocess_vietASR_ssl.py`
Filters cuts by duration (removes too-short or too-long segments), normalizes sampling rates.

#### `compute_fbank_vietASR_ssl_splits.py`
Computes fbank features for all sharded manifest files in parallel (via Python `multiprocessing`).

#### `cut2text.py`
Utility to extract text transcripts from a labeled lhotse `CutSet`. Used to build LM training data.

#### `prepare_char.py` / `prepare_lang.py`
Build character-level or word-level language files (`lang/`) for CTC decoding with an n-gram LM.

---

### 4.3 `SSL/shared/` — Shared Bash Utilities

#### `parse_options.sh`
Kaldi-style argument parser for bash scripts. Allows `--key value` argument passing to shell scripts.

#### `make_kn_lm.py` / `ngram_entropy_pruning.py`
Build Kneser-Ney n-gram language models and apply entropy pruning for LM-fused decoding.

#### `convert-k2-to-openfst.py`
Converts a k2 `Fsa` graph to OpenFST format for external LM integration.

---

### 4.4 `SSL/scripts/` — SSL Launch Scripts

| Script | Stage | Description |
|--------|-------|-------------|
| `learn_vietASR_kmeans.sh` | 2a | Trains k-means on ~100h encoder representations |
| `extract_vietASR_kmeans.sh` | 2b | Applies k-means to all unlabeled audio → pseudo-labels |
| `run_ssl.sh` | 3 | HuBERT-style pretraining on pseudo-labeled data |
| `finetune.sh` | 4 | Fine-tunes pretrained SSL model on labeled ASR data |
| `finetune_ASR_checkpoint.sh` | 4 | Fine-tunes the public `viet_iter3` checkpoint on new data |
| `decode.sh` | eval | Evaluates a fine-tuned checkpoint |

---

### 4.5 `SSL/zipformer_fbank/` — SSL Model Source Code

Most files are mirrors of `ASR/zipformer/`. Only unique files are described:

#### `pretrain.py` ★
HuBERT-style pretraining loop. Target: k-means cluster IDs (integers), not transcript text. Loss: cross-entropy on frame-level cluster ID predictions. Uses random frame masking before feeding to encoder.

#### `finetune.py` ★
ASR fine-tuning script for the pretrained model. Loads a pretrained checkpoint, optionally freezes layers, and trains with standard RNN-T loss on labeled data.

#### `hubert_ce.py` ★
SSL model wrapper. Adds a linear projection head on top of the Zipformer encoder outputs and computes cross-entropy loss against k-means targets. Also handles the masking strategy (randomly masking ~15% of frames).

#### `ssl_datamodule.py`
DataLoader for unlabeled data with k-means labels. Reads manifests with cluster IDs stored as custom supervision fields and yields `(features, mask, targets)` batches.

#### `tri_scheduler.py`
Triangular learning rate scheduler used during SSL pretraining (linear warmup → linear decay).

#### `extract_kmeans_scripts/learn_kmeans.py`
Trains a scikit-learn `MiniBatchKMeans` on encoder representations extracted from ~100h of audio. Saves the k-means model to disk.

#### `extract_kmeans_scripts/extract_kmeans.py`
Applies a trained k-means model to all audio segments. For each frame, assigns the nearest cluster centroid ID. Writes results into new lhotse manifest files (the SSL training targets).

#### `extract_kmeans_scripts/build_cut_for_kmeans.py`
Builds a small ~100h subset `CutSet` used for training the k-means model.

## 5. `POC/` — Proof-of-Concept Inference Web Application

A fully functional 3-tier web application demonstrating real-time and batch Vietnamese ASR inference. Built with **Clean Architecture** principles.

```
POC/
├── README.md
├── apps/
│   ├── asr-server/       # FastAPI model inference server (Python)
│   ├── web-backend/      # FastAPI gateway backend (Python, Clean Arch)
│   └── web-frontend/     # React + Vite + TypeScript SPA
├── docker/
│   └── docker-compose.yml  # PostgreSQL + MinIO containers
├── docs/                 # Deployment guides
├── scripts/
│   └── clean.sh          # Remove __pycache__, .pyc, node_modules cache
└── specs/                # System specs and contracts
```

**System architecture:**
```
React Frontend ←→ FastAPI Web Backend ←→ FastAPI ASR Server (model)
                        ↕                       ↕
                  PostgreSQL DB          PyTorch/k2 checkpoint
                  MinIO Storage
```

---

### 5.1 `POC/apps/asr-server/` — ASR Model Inference Server

**Technology:** Python, FastAPI, PyTorch, k2

A dedicated microservice that loads a trained Zipformer2 checkpoint and serves predictions.

#### `src/main.py`
FastAPI application with three endpoints:
- `GET /health` — model readiness check
- `POST /transcribe` — batch file upload; decodes WAV bytes → transcript JSON. Accepts optional `config` JSON: `{"method": "modified_beam_search", "beam_size": 4}`
- `WebSocket /api/stream` — streaming protocol:
  1. Client sends `{"event": "handshake", "config": {...}}`
  2. Server replies `{"event": "handshake_ok", "session_id": "..."}`
  3. Client streams raw PCM binary chunks
  4. Server replies `{"event": "transcript_update", "text": "...", "is_final": false}`
  5. Client sends `{"event": "stop"}`
  6. Server replies `{"event": "finished", "full_transcript": "..."}`

#### `src/models/k2_decoder.py`
`K2Decoder` — wraps the TorchScript model. Handles:
- Loading JIT checkpoint and token table from env var paths
- Audio preprocessing (resample to 16kHz, extract fbank)
- Running `greedy_search` or `modified_beam_search` on encoder output
- Returning `{"transcript": "...", "duration": 2.3}` response dict

#### `src/models/decode_stream.py`
`DecodeStream` — session object for WebSocket streaming. Accumulates raw PCM audio chunks and is passed to `K2Decoder.decode_stream_session()` for incremental decoding.

**Configuration (`.env`):**
```ini
ASR_CHECKPOINT_PATH=/path/to/epoch-12.pt    # TorchScript checkpoint
ASR_TOKENS_PATH=/path/to/tokens.txt
ASR_SERVER_PORT=8001
```

---

### 5.2 `POC/apps/web-backend/` — Gateway Backend

**Technology:** Python, FastAPI, SQLAlchemy (asyncio), MinIO, Clean Architecture

Acts as the API gateway between the React frontend and the ASR server. Handles file storage, FFmpeg transcoding, and database logging.

**Architecture layers (`src/`):**

| Layer | Path | Responsibility |
|-------|------|----------------|
| `domain/` | Business entities | `Transcription`, `AudioFile` data models |
| `usecases/` | Application logic | `TranscribeAudioUseCase`, `StreamAudioUseCase` |
| `adapters/` | Interface implementations | DB repos, MinIO storage, ASR HTTP client |
| `frameworks/` | FastAPI + SQLAlchemy | Controllers, DB session, app factory |

**Key adapters:**
- `adapters/asr_client/` — HTTP/WebSocket client to the ASR server
- `adapters/database/` — SQLAlchemy async repository for transcription history
- `adapters/storage/` — MinIO S3-compatible object storage client
- `adapters/controllers/` — FastAPI route handlers (thin wrappers over use cases)

**Configuration (`.env`):**
```ini
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/vietasr
```

### `external/icefall/`
The [icefall](https://github.com/k2-fsa/icefall) framework provides:
- `icefall/checkpoint.py` — `save_checkpoint`, `load_checkpoint`, `average_checkpoints`
- `icefall/diagnostics.py` — per-parameter gradient/activation logging
- `icefall/dist.py` — DDP `setup_dist` / `cleanup_dist` wrappers
- `icefall/utils.py` — `AttributeDict`, `MetricsTracker`, `setup_logger`, `str2bool`
- `icefall/hooks.py` — hooks for detecting Inf/NaN gradients

The `egs/` directory contains 43 recipe directories for different datasets — **not used by VietASR directly**, just part of the icefall upstream.

### `external/k2/`
The [k2](https://github.com/k2-fsa/k2) library: CUDA-accelerated WFST operations used by `beam_search.py` for fast beam search and lattice decoding.

> **Important:** These are submodules. After cloning, run: `git submodule update --init --recursive`

## 11. `viet_iter3_pseudo_label/` — Pre-trained Checkpoint

A Git LFS tracked directory containing the publicly released model checkpoint from Iteration 3 of VietASR. Hosted on [HuggingFace Hub](https://huggingface.co/zzasdf/viet_iter3_pseudo_label).

```
viet_iter3_pseudo_label/
├── data/
│   └── Vietnam_bpe_2000_new/
│       └── tokens.txt      # BPE vocabulary (2000 tokens)
└── exp/
    └── epoch-12.pt         # Trained checkpoint (~66M params, full config)
```

> **Note:** This checkpoint uses the **original (non-Small)** architecture: `encoder_dim=192,256,384,512,384,256`. If you retrain with Zipformer-Small defaults, the checkpoint shapes will not match — you must train from scratch or use `strict=False` partial loading.

**Usage:**
```bash
python ASR/zipformer/pretrained.py \
  --checkpoint viet_iter3_pseudo_label/exp/epoch-12.pt \
  --tokens viet_iter3_pseudo_label/data/Vietnam_bpe_2000_new/tokens.txt \
  --method modified_beam_search \
  input-test/video-test-001-small.wav
```

## 12. Data Flow: End-to-End Training Walkthrough

### Supervised Data Expected Layout
```
ASR/download/supervised/
├── train/dataset_name/*.wav + filename.trans.txt
├── dev/...
└── test/...
```
Where `filename.trans.txt` contains lines: `audio_id transcription text`

### Unsupervised Data Expected Layout
```
SSL/download/ssl_data/*.wav   (after VAD segmentation)
```

### Generated Data (auto-created by scripts)
```
ASR/data/
├── manifests/         # lhotse RecordingSet + SupervisionSet (.jsonl.gz)
├── fbank/             # Compressed CutSet with fbank features
└── lang_bpe_2000/     # bpe.model, tokens.txt, lexicon.txt

SSL/data/
├── manifest_data/     # Unlabeled lhotse manifests
├── ssl_data/          # Fbank features for unlabeled audio
│   └── data_split/    # Sharded cuts (vietASR-ssl_cuts_*.jsonl.gz)
└── ...                # K-means labeled manifests (iter1, iter2, ...)

{ASR,SSL}/exp/         # Training checkpoints (epoch-N.pt, averaged_model.pt)
```

## 13. Key Hyperparameters Reference

### Current Zipformer Architecture (as of this commit)

All controlled in `ASR/zipformer/train.py` → `add_model_arguments()`. **This is the only file to edit for architecture changes.**

| Parameter | Current Default (Zipformer-Small) | Description |
|-----------|----------------------------------|-------------|
| `--num-encoder-layers` | `"2,2,2,2,2,2"` | Blocks per stack (6 stacks) |
| `--encoder-dim` | `"192,256,256,256,256,256"` | Hidden dim per stack |
| `--feedforward-dim` | `"512,768,768,768,768,768"` | FF hidden dim per stack |
| `--num-heads` | `"4,4,4,8,4,4"` | Attention heads per stack |
| `--cnn-module-kernel` | `"31,31,15,15,15,31"` | Conv kernel per stack |
| `--query-head-dim` | `"32"` | Q/K dim per head (constant) |
| `--value-head-dim` | `"12"` | V dim per head (constant) |
| `--pos-head-dim` | `"4"` | Positional dim per head |
| `--pos-dim` | `48` | Positional encoding dim |
| `--downsampling-factor` | `"1,2,4,8,4,2"` | U-Net frame rate factors |
| `--encoder-unmasked-dim` | `"192,192,256,256,256,256"` | Feature mask dim (≤ encoder_dim) |
| `--decoder-dim` | `512` | RNN-T decoder embedding |
| `--joiner-dim` | `512` | Joiner hidden dim |

### Model Size History

| Variant | Params | `encoder_dim` | `num_encoder_layers` | `feedforward_dim` |
|---------|--------|---------------|---------------------|------------------|
| **Zipformer-Small (current)** | **~30M** | **192,256,256,256,256,256** | **2,2,2,2,2,2** | **512,768,768,768,768,768** |
| Repo original (before this change) | ~66M | 192,256,384,512,384,256 | 2,2,3,4,3,2 | 512,768,1024,1536,1024,768 |
| Upstream icefall Large | ~80M+ | 192,256,512,512,512,256 | 2,4,4,8,4,4 | 768,1024,1536,2048,1536,1024 |

### Training Hyperparameters

| Parameter | Default | Meaning |
|-----------|---------|---------|
| `--num-epochs` | 300 | Total training epochs |
| `--max-duration` | 1000 | Max audio seconds per batch |
| `--world-size` | 4 | Number of GPUs (DDP) |
| `--use-fp16` | 1 | Mixed precision training |
| `--enable-spec-aug` | 1 | SpecAugment data augmentation |
| `--seed` | 1332 | Random seed |
